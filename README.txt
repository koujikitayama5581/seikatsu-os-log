生活OSログ Ver.2.0／iPhone PWA改良版

【更新前に必ず】iPhoneのVer.1.39アプリで「バックアップ・復元」→「JSONを保存」。安全な場所にコピーしてください。

【内容】左下メニュー（メニュー画面を除く）、5週カレンダー中央週を今日、心/体の疲労0～9・2色塗り分け、過去の疲労値は心へ引き継ぐ、グラフ2系列、臨時収入メモ、明日の日割り予算。

【重要】データ保存キー lifelog-prototype-v127 は以前のまま。既存JSONとも互換性を維持。今のiPhoneのホーム画面アプリは削除しないでください。

【公開時】GitHubリポジトリ seikatsu-os-log のルートに、index.html、manifest.webmanifest、sw.js、アイコン3枚を上書きアップロードしてCommit。README.txtも任意で更新可。URLは従来と同一。

【テスト】まずMacまたは別のテスト環境で表示・操作を確認。その後、iPhoneでバックアップを取ったことを確認してから公開版を更新。ホーム画面アプリが古いままの場合はアプリを再起動し、Safariの同一URLも開いてキャッシュ更新を確認。

【CSV】日別CSVに心・体・旧疲労の列を追加。従来のfatigue値は破棄しません。

GitHubにJSON（生活記録）をアップロードしないでください。
